# Livrable 05 — Documentation technique et transfert de connaissances

**Compétence** : C27

Ce dossier constitue l'ensemble documentaire de reprise pour OpsTrack Field Service.

## Contenu

| Fichier | Objet |
|---|---|
| `documentation_technique.md` | Structure de l'application, composants, dépendances |
| `api.md` | Documentation des endpoints REST versionnés (`/api/v1`) et du webhook |
| `CHANGELOG.md` | Journal des modifications effectuées pendant l'épreuve |
| `journal_securite.md` | Liste des failles identifiées, correctifs, et mesures restantes |
| `note_passation.md` | Note de reprise pour la personne qui prend la maintenance |

## Portée

La documentation couvre exclusivement le code métier OpsTrack et les composants d'exploitation. Elle exclut la documentation des dépendances tierces (Laravel, Next.js, Apache, MySQL, MongoDB, Redis) dont la référence officielle est plus à jour et exhaustive.
