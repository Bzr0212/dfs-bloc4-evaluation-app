# Documentation technique — OpsTrack Field Service

## Vue d'ensemble

Application Laravel 12 (PHP 8.4) de gestion d'interventions terrain, complétée par un microservice Next.js pour un tableau de bord dispatch et un webhook PHP pour l'ingestion d'événements externes. Base MySQL pour les données métier, MongoDB pour les logs applicatifs, Redis pour le cache.
